# Ruler Tools logo concepts — v3

Third pass: quieter, interface friendly marks.

- `01-variable-scale.svg` turns measurement into a set of graduated bars. Charcoal `#202A36`, ivory `#F1EBDD`, and copper `#EFB05D` are suited to a compact product identity.
- `02-endpoint-system.svg` uses dimension endpoints and a nested right angle. Purple `#392E68` and apricot `#FFB25B` make a distinctive alternative.

Both SVGs are transparent and editable. The left-hand geometry is intended to remain recognizable at small sizes.
