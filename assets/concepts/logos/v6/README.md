# Ruler Tools logo concepts — v6

Both editable SVG concepts start from [v5's integrated crown protractor](../v5/02-integrated-crown-protractor.svg). Gold `#F5BD4F` and slate/navy `#253F68` exchange positions: the outer crown, protractor graduations, pivot, and RULER wordmark become gold; the inset measurement arc becomes slate/navy. The warm gold TOOLS text remains `#B67714`.

- `01-five-point-crown-protractor.svg` adds a symmetrical outer point on each side, giving the crown five points while keeping the protractor integrated into the same silhouette.
- `02-measuring-tools-crown-protractor.svg` keeps the original three-point crown and adds two slim rulers emerging from its ends. Their gold outlines and graduations surround slate/navy interiors, and their mirrored 24-degree angles balance the icon.

The wordmark positions, font settings, protractor geometry, and 760 × 180 canvas are retained. Earlier versions remain unchanged. No app code, tests, or builds were run for this concept revision.
