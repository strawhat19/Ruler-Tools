# Ruler Tools logo concepts — v4

This round pairs a crown with recognizable measuring instruments.

- `01-crowned-ruler.svg` uses a three-point crown over a ruler band; the white graduations keep the measuring function explicit.
- `02-crown-protractor.svg` puts the crown behind a semicircular, graduated protractor for an angle-measurement direction.

Both use navy `#233858` / `#253F68`, gold `#F5BD4F`, and white `#FFFFFF`. Each is an editable SVG lockup with a transparent surrounding canvas.
