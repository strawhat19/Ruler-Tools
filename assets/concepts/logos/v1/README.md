# Ruler Tools logo concepts — v1

First pass: familiar measurement cues with a clear product name.

- `01-calibrated-r.svg` combines an R monogram with ruler graduations. Midnight `#14243B`, ivory `#F6F2E9`, and amber `#F5B544` make a compact tool icon.
